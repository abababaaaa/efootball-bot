流程可视化面板

实时展示当前页面、探针得分、导航路径、比赛阶段

面板布局

① 当前页面卡片
大字号显示当前 PageNode Id
下方：rawScore + evidence 关键词
背景色按页面类型着色
替代当前的「画面 → xxx」日志
② 探针得分条
Top-5 候选页面的 rawScore 横向条形图
绿色=命中，灰色=未达阈值
鼠标悬停显示 evidence 详情
调试画面误判的核心工具
③ 导航路径图
页面图谱的局部可视化
当前页高亮，目标页闪烁
已走过的边实线，计划走的边虚线
BFS 寻路结果可视化
④ 比赛阶段指示
7 阶段进度条：PreMatch→Kickoff→Playing→...
当前阶段高亮，已完成阶段打勾
滑动超时剩余时间倒计时
MatchFlow 状态实时展示

数据来源（事件驱动）

Worker → GUI 事件流（命名管道）：
  screen: { page, rawScore, evidence, override }
  nav: { from, to, path: [...] }
  flow: { stage, deadline, forfeit }
  overlay: { id, dismiss }
  probe: { candidates: [{page, score, evidence}] }

价值

  • 替代大量日志，一眼看清当前状态
  • 画面误判时直接看到 Top-5 得分，快速定位关键词问题
  • 导航卡顿时看到路径图，定位哪条边失效

实现要点

  • 事件从 Worker 进程通过管道发到 GUI
  • GraphWindow 已存在骨架，可复用
  • 探针得分条是调试核心，优先级最高
