# eFootball YOLO 自动标注规范（AI 标注用）

图片：1227×720 的 eFootball 游戏窗口截图（顶部约 20px 是系统标题栏，不算游戏画面）。
输出：YOLO 格式 txt，每行 `class cx cy w h`，全部为归一化 0~1 的值（像素坐标除以 1227 和 720），文件名与图片同名（.jpg → .txt）。

## 类定义（class id 必须准确）

| id | 类名 | 定义 |
|----|------|------|
| 0 | player_card | 竖版球员卡（含球员肖像、整体评级、位置+数值徽章）。轮播横幅里的小卡、详情页大卡都算。 |
| 1 | btn_back | "返回"按钮：左下角蓝色高亮条（B 圆标 + "返回"文字），或左上角圆形返回箭头按钮。 |
| 2 | btn_confirm | 蓝色推进按钮："确定 / OK / 下一步 / 继续 / 决定"（通常带 A 圆标）。注意："详情(X)"、"商品详情(Y)"等查看类按钮、普通菜单项**不算**。 |
| 3 | coin_bar | 右上角货币余额条（M 圆标 + 数字如 93,250）。比赛画面里的比分牌**不算**。 |
| 4 | main_menu | 主菜单顶部导航条（含"游戏主菜单 / 商店 / 学院 / 额外选项"的整条黑底圆角条）。 |
| 5 | item_row | 商品/物品列表的单行（左图标 + 名称 + 右侧价格），一行一框。比赛结果列表行、设置项**不算**。 |

## 规则

1. 每张图片必须生成同名 txt，**完全无 6 类目标时写空文件**（如比赛画面）。
2. 只标清晰可见的目标；边缘截断超过 60% 的跳过。
3. 界面相同的相邻帧（时间戳相近、内容一致）直接复用坐标，不必重新估计。
4. 看不清 / 不确定的目标宁可不标，不要猜。
5. 先用 Read 读图（多模态），仔细估计每个目标的边界框，换算归一化后写入 txt。
6. 写完后核对：txt 数量 = 分配的图片数量。
