# eFootball 挂机助手

> **为实况足球（eFootball）端游打造的自动化挂机工具 —— 国际服 / 国服双支持，自动比赛、自动领奖、自动切换，解放双手。**

---

## ✨ 核心功能

| 服务器 | 模式 | 说明 |
|---|---|---|
| 🌍 国际服 | **我的联赛**（练级球员需手动更换） | 自动踢比赛刷经验，球员升级后需手动更换阵容 |
| 🌍 国际服 | **周教练活动** | 自动识别奖励是否领完，领完自动切换下一个活动 |
| 🇨🇳 国服 | **AI 教练活动** | 自动识别奖励是否领完，领完自动切换下一个活动 |

## ⚙️ 运行环境

- **平台**：Windows 10/11（x64）
- **依赖**：ViGEmBus 虚拟手柄驱动（自动检测，可一键安装）
- **.NET**：.NET 10 Desktop Runtime

## ⚠️ 重要声明

### 分辨率建议
理论上支持全分辨率，但**强烈建议游戏以「窗口化 720p」运行**。分辨率过高会导致后台画面捕获与 OCR 识别卡顿、CPU 占用飙升，影响挂机稳定性。
