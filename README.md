## 国际服模块

### 我的联赛

自动完成联赛比赛、领取奖励，带断点续跑与流程记忆。三个进阶能力：

- **只打关键比赛**：非关键场次自动跳过（杀进程重启游戏再进），只打关键战；带熔断保护（连续失败 / 次数上限自动停），跳过场次不计入完成场次
- **满级自动换人**：替补有人满级就换上，按「整体评价」排序取最低评价的亮卡换上，配开赛前确认弹窗；带独立「一键测试」入口（不启动挂机也能验一次换人）
- **难度核对**：进入「选择赛事等级」页自动比对设置难度，不一致自动改选

### 周活动

自动判断奖励是否领满，领满自动切下一个活动。支持：

- 单场周活动（「选择赛事等级」整页识别 + 滚动选档）
- 挑战清单（逐张完成，已完成活动拉黑防死循环）
- 活动地图（当前位置 + 下一步 + 奖励判定）
- 活动列表 / 介绍页 / 阵容配置（活动加成阵容自动配）全流程导航

### AI 天梯联赛

组别循环冲级，可设达到某个组别自动停止；组别解析带位置过滤，识别退化时有盲试兜底。

### 赛前快捷设置

一键打开游戏自带 `Settings.exe`（三级定位：运行中进程锚定 → 上次路径记忆 → Steam 库），旁边配「快速打开游戏」。

## 国服模块

### 天梯巅峰赛

识别本周可参赛场次与倒计时，0 场自动停止；鼠标点击教练卡进入，单场比赛循环刷。赛后的段位积分页与赛后小结弹窗是客户端里的网页层 UI（只吃鼠标/键盘提示键，不吃虚拟手柄），自动按按钮位置点掉。

### 周活动

国服周活动形态比国际服多，程序按页面结构分流：

- **杯赛型**（冠军赛）：对阵表推进 → 阵容配置 → 打满全程（小组赛 + 淘汰赛）
- **巡回赛型**：活动设置核验（教练模式 + 完全托管）→ 循环刷到奖励拿满
- **挑战清单型**：识别目标卡（首张上锁卡的前一张）→ 逐张打满；积分制挑战会核对积分，未达标继续打、不提前换卡
- **选择赛事等级页**：识别聚焦行并滚动选档

### 我的联赛

与国际服同款玩法，自动核对难度（国服难度页没有底行确认结构时走列表游走 + 勾选），打完自动循环。

## 工具与增强

### 网络监测

- **服务器延迟清单**：内置 160 条 eFootball 服务器（带中文国家 / 城市名），游戏服走 ICMP、更新服走 TCP，一键测全部，支持按延迟排序与筛选
- **游戏内连接监控**：Npcap 抓本机 UDP，自动认出比赛连接并每秒 ping 远端；显示延迟 / 丢包 / 最小·平均·最大，可开**置顶悬浮窗**盖在游戏画面上边打边看
- **对战模式判定**：自动区分「服务器 / P2P / 匹配前测速」
- **对战日志**：每场比赛结束自动写一行到 `data\network\matchlog.csv`（模式、远端地址、区域、延迟、丢包、时长）

### 对战线路

- **强制 P2P 匹配**：屏蔽游戏到测速服务器的 UDP 端口（5521 / 10000 / 30000 / 50000），让匹配走点对点。规则写在 Windows 防火墙并绑定 `eFootball.exe`，**不安装任何驱动**（不用 WinDivert，不会被杀软误报），一键关闭即删除规则还原。可选「同时屏蔽 TCP 服务器模式」（TCP 30000-35000、5736）。注意：匹配等待会明显变长
- **更新服测速加速**：解析科乐美更新 CDN 的全部边缘 IP，测速后把最快的写进 hosts（独立标记块，可一键还原）

### GitHub 加速

**GitPort 内核**：本地代理接管 GitHub 全家族（clone / push / Release / raw / 网页），带真实 IP 表免疫 DNS 污染，不影响其它网站流量。内核从开源项目下载（约 8 MB，走镜像链），带可视化工作台。另有 GitHub 域名延迟测速，用来判断加速是否生效。

### 窗口防卡死

游戏窗口不在屏幕上、停靠后回不来、或找不到窗口时，一键移回原位置或主屏居中（国服 / 国际服通用）。

## 后台挂机与稳定性

| 能力 | 说明 |
|---|---|
| **窗口停靠后台** | 游戏缩到屏幕外后仍能捕获与操作，可一边做别的事（不改游戏分辨率） |
| **捕获降级链** | WGC → Vortice/DXGI → GDI 三层自动降级；黑帧 / 空画面自动归因，区分「游戏卡死」与「显卡问题」 |
| **虚拟手柄接管** | ViGEmBus 虚拟手柄模拟按键，真实手柄不会被抢；玩家 1 设备占用自动释放 |
| **驱动自检** | 手柄驱动状态一键自检，直接给结论，不用截图 |
| **拟人节奏** | 按键间隔抖动 + 随机休息 + 作息调度（可设挂机时段），避免机械式全天挂机 |
| **六个模块统一操作** | 开始 → 一键结束 / 暂停（置暗，再点继续）/ 发现问题手动停止（自动截图 + 打包反馈） |
| **单机多开隔离** | 每个实例独立配置与锁，可同时跑两份互不干扰 |

## 通知与远程监控

- **Webhook 实时推送**：结束 / 异常 / 比赛完成 / 球员满级 / 警告与错误 / 运行摘要，推到你自己的服务。兼容 Server酱、PushPlus、飞书 / 钉钉 / 企微群机器人，带合并窗口与每日上限控量
- **局域网监控页**：手机连同一 WiFi，微信内置浏览器打开 `http://本机IP:端口/?t=token`，看状态、实时日志、比赛与满级动态，并可暂停 / 继续 / 单步。只监听本机网卡，不上传任何数据

## 自动更新

多通道自动选路（**国内直连主源 → 加速镜像链 → GitHub 直连**），**每个候选下载完立即做 SHA256 校验，不匹配就换下一个通道**；支持**差量补丁**（只下变化的部分，通常几 MB）。

主源是对象存储（默认 Cloudflare R2 公开桶）上的两样东西：一份几十字节的版本清单 `latest.json`（测试版读 `latest-pre.json`）和带版本号的安装包 `EfootballBot-<版本>.exe`。客户端只读清单就能判断有没有新版，**不经过 GitHub 也能量到、能下**；清单里的 `file` / `sha256` / `size` 由 CI 发版时写入，哈希对不上就弃用该通道、换下一个。差量补丁（`patches/patch-<旧>-to-<新>.bin`，通常几 MB）也放在主源上，常规升级同样不碰 GitHub。

换源不用重新编译：`data\config.json` 的 `Update.PrimaryBaseUrl` 优先于程序内置地址，环境变量 `EFOOTBALL_UPDATE_BASE` 优先级最高（自测新桶时用）。

> 开通主源（维护者，一次性）：Cloudflare → R2 建桶 → 开启 r2.dev 公开访问 → 建 Object Read & Write 的 API Token → 仓库 Secrets 填 `R2_ACCOUNT_ID` / `R2_ACCESS_KEY_ID` / `R2_SECRET_ACCESS_KEY` / `R2_BUCKET` → 把桶地址填进 `Updater.BuiltInPrimaryBaseUrl` 发一版。之后每次打 tag，CI 自动上传版本包与清单（桶里只保留最近 3 个版本包）。详见 [主更源设计](docs/superpowers/specs/2026-11-07-primary-update-source-design.md)。

更新用 rename-swap 方式替换自身：旧 exe 先改名 → 新 exe 就位 → 失败自动回滚 → 重启后清理备份。

## 快速开始

1. **下载**：从 [Releases](https://github.com/abababaaaa/efootball-bot/releases) 取 `EfootballBot.exe`（单文件，下载即用）
2. **以管理员身份运行**：游戏本身提权运行，本程序不提权会点不动游戏、抓不到手柄
3. 首次启动自动做环境检测（虚拟手柄驱动 / 捕获 / OCR / 游戏窗口），缺虚拟手柄驱动会引导安装
4. **建议游戏以 1280×720 窗口化运行**：所有识别与点击以 720p 为基准校准，分辨率越高越容易卡顿、识别变差
5. 选服务器 → 选模块 → 点模块页的「开始」，或直接用全局热键启动 / 暂停 / 结束

> 数据全部落在程序目录的 `data\`（配置、日志、截图、训练帧），不写 `%APPDATA%`，拷走整个文件夹即可迁移。

## 常见问题

**Q：点了开始没反应 / 点击无效**
以管理员身份运行本程序。游戏是提权进程，非管理员进程发出的输入会被系统拦截。

**Q：找不到游戏窗口 / 窗口不见了**
点左栏「窗口防卡死」移回屏幕；仍不行就把游戏切成窗口化再试。

**Q：识别不准、按错键**
把游戏调成 1280×720 窗口化；画质设「低」或「中」，关掉动态模糊 / 抗锯齿等后期效果。

**Q：真实手柄被占用 / 不认手柄**
程序用虚拟手柄接管，挂机期间真实手柄不参与；设置 → 手柄与输入 可禁用真实手柄设备节点，结束后自动恢复。

**Q：连接监控启动失败**
未安装 Npcap，或未以管理员运行。装 Npcap 时勾选「Install Npcap in WinPcap API-compatible Mode」。

**Q：强制 P2P 之后匹配很久**
这是预期行为——屏蔽测速端口后只能等点对点对手。不想等就在「网络监测 → 对战线路」点关闭，规则立即删除。

**Q：国服模块能用吗**
能，但国服页面改版频繁，识别可能滞后。遇到卡住 / 误判 / 乱按，请带反馈包进群反馈（见下）。
