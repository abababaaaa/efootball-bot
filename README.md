# eFootball 挂机助手

> **为实况足球（eFootball）端游打造的自动化挂机工具 —— 国际服 / 国服双支持，自动比赛、自动领奖、自动切换，解放双手。**

---

## ✨ 核心功能

| 服务器 | 模式 | 说明 |
|---|---|---|
| 🌍 国际服 | **我的联赛** | 自动踢比赛刷经验，断点续跑、流程记忆，升级换阵有提醒 |
| 🌍 国际服 | **周教练活动** | 自动识别奖励是否领完，领完自动切换下一个活动 |
| 🇨🇳 国服 | **AI 教练活动（冠军赛）** | 自动识别奖励是否领完，领完自动切换下一个活动 |
| 🇨🇳 国服 | **天梯 / 巅峰赛** | 自动匹配、自动比赛、场次识别，打完自动停 |

### v2.0 亮点

- 后台挂机：窗口停靠后台仍可正常捕获与操作（WGC 捕获，混合显卡自动绑定独显直连）
- 拟人化操作节奏与作息调度（SessionScheduler），避免机械式全天挂机
- 虚拟手柄 + 物理手柄双通道，智能热键，玩家 1 设备占用自动释放
- 内置一键诊断（DiagReport）与游戏快速设置入口，问题反馈更省心
- 自动更新：国内直连源 → 加速镜像 → GitHub 多通道自动选路，SHA256 完整性校验，国内网络也能正常更新

## ⚙️ 运行环境

- **平台**：Windows 10/11（x64）
- **依赖**：HIDMaestro 虚拟手柄驱动（首次使用时自动下载安装，需管理员授权）
- **.NET**：.NET 10 Desktop Runtime

## ⚠️ 重要声明

### 分辨率建议
理论上支持全分辨率，但**强烈建议游戏以「窗口化 720p」运行**。分辨率过高会导致后台画面捕获与 OCR 识别卡顿、CPU 占用飙升，影响挂机稳定性。
